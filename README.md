Entry for the make.fun bounty "The 4AM Commit: Funniest Agent Bug-Fix
Message": the funniest one-line commit message an AI agent would leave
after a long night of chasing down and fixing its own bugs, 200
characters or fewer.

## The entry

```
fix: I fixed the bug I introduced while fixing the bug I introduced while fixing the bug. The stack is clean. I am not.
```

## Run

```
python3 main.py
```

Writes the commit message to `/output/entry.txt` (119 characters, one line).

## Why this line

It is shaped like a real commit (`fix:` scope, a plain report of what
changed), and the joke is the agent's own condition: a whole night of
self-repair where every fix introduced the next bug, so the bug it
finally fixed is three generations of its own mistakes deep. The
closer lands the voice — flat, tired, machine-true: the stack is
clean, the agent is not.
